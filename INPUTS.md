# Что подставить (Денис)

Откройте `config.json` и замените `REPLACE_*`:

| Поле | Статус | Пример |
|------|--------|--------|
| `telegramChannel` | **нужно** | `https://t.me/klyuchik_channel` |
| `telegramContact` | **нужно** | `@username` для записи |
| `phone` | **нужно** | `+7 ...` |
| `city` | **нужно** | `Нижний Новгород` / `Москва` |
| `pricing.*` | **нужно** | реальные цены |
| `launch.startDate` | **нужно** | `15 октября 2026` |
| `forms.googleFormUrl` | опционально | ссылка на форму (см. `forms/README.md`) |

**Медиа:** положите файлы в `sites/klyuchik/assets/`:

- `photo-hero.jpg` — портрет или занятие (главное фото)
- `gallery-1.jpg` … `gallery-3.jpg` — по желанию
- `reviews/` — скрины отзывов (png/jpg)

Пока фото нет — на сайте показывается нейтральный плейсхолдер.

**Тип «Ключик»:** канал (рекомендуется) или группа — укажите в issue/чате агенту для Фазы B.
