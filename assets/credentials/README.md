## Не класть на сайт

Волонтёрские благодарности, #МЫВМЕСТЕ, детские конкурсы, чужие дипломы — только в личный архив.

## Видео

Ролик с Repetitor или своё приветствие: `assets/media/teacher-intro.mp4` — потом можно добавить в блок «Видео» через `config.json` → `media.channel.videoItems`.

После замены файлов: `./publish-github.sh klyuchik-school`.
