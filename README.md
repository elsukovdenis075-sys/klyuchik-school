# Проект «Ключик» — Telegram и лендинг

Материалы для продвижения педагогических услуг **Ирины Васильевны Елсуковой**.

## Быстрый старт

1. Заполните [`config.json`](config.json) — см. [`INPUTS.md`](INPUTS.md).
2. Положите фото в [`assets/`](assets/).
3. Тексты для Telegram — папка [`telegram-pack/`](telegram-pack/).
4. Сайт: откройте [`index.html`](index.html) через локальный сервер (см. [`DEPLOY.md`](DEPLOY.md)).
5. Инструкция для мамы: [`docs/instrukciya-dlya-mamy.md`](docs/instrukciya-dlya-mamy.md).
6. Запуск набора: [`launch/LAUNCH-SEQUENCE.md`](launch/LAUNCH-SEQUENCE.md).

## Структура

```
sites/klyuchik/
├── config.json          # контакты, цены, набор
├── index.html           # лендинг
├── site.js / styles.css
├── telegram-pack/       # описание, закреп, посты, ЖК
├── launch/              # сценарий первой недели
├── forms/               # как сделать Google Form
└── docs/                # инструкция для мамы
```
